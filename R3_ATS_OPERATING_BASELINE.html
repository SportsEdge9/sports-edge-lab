    Model specification

    Input: 149 recovered 2026 archived game scores + spread-line observations. Outcome is actual home margin minus historical home favorite margin. Independent home intercept plus opponent-adjusted team strengths fitted by ridge regression (team alpha 85, intercept alpha 25; 6-week recency half-life). Projected home margin equals entered home favorite margin plus fitted residual. Probability model uses a normal margin spread σ=13.5 points, with explicit push probability on whole-number lines. These choices are reconstruction assumptions, not verified original R3 settings. EV uses each entered side's actual American price. No automatic live odds feed, no verified source timestamp, and no real-time injury/QB information.
